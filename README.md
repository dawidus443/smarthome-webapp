# SmartHome WebApp

This repository contains the **web application** part of the project:

> **Smart Home System Using Selected Control and Monitoring Elements**  
> by Dawid Badora,  
> Bachelor’s thesis project (Automation and Robotics, 7th semester).

---

## Project Overview

The goal of the project was to design a **modular smart home monitoring system** utilizing microcontrollers and various sensors to collect environmental data and transmit it to a web application in real-time.

### System Modules
- **Weather Module** — measures temperature and humidity  
- **Fire Detection Module** — detects smoke  
- **Anti-Burglary Module** — detects motion and door/window opening using ultrasonic and PIR sensors  

### Additional Feature
A **component selection calculator** allows users to design a tailored smart home system without needing expert help.

---

## About This Repository

This repo contains the **web application** which provides:  
- Real-time monitoring and control of system modules  
- Interactive user interface for communication with the microcontroller server  
- Home design module with a calculator to estimate the required number of modules  

### Technologies Used
- **Frontend:** Angular  
- **Backend:** Spring Framework  
- **Database:** MySQL  

The microcontroller firmware and hardware design are handled separately.
